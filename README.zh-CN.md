**中文** · [English](README.md)

> **你回测出来的，不是你真会交易的那条策略。**
> `strategy-audit` 在真金白银之前，先帮你把这个缺口找出来。

这是一个本地离线工具，审的是量化研究里最贵、也最容易被忽略的一段：从一张**权重表**到一条**净值曲线**的这段路。它不帮你找因子、不预测涨跌、也从不联网——它读你的文件、重算你的组合，然后只问一个问题，问得很大声：

> **你报出来的这条净值，真的是这套持仓、按当时拿得到的价格、在真正能成交的那些天，算得出来的吗？**

---

## 问题出在哪

你辛苦找了几个因子、调了参数，平台回测年化不错。下一步顺理成章是看 Sharpe、回撤、胜率，然后开模拟盘。

先别急。

大多数回测失败不在因子本身，而在**最后一公里**——把一份持仓变成一条报出来的净值的那一步：

- 权重表对不上你报的净值；
- 停牌股被悄悄当成没发生；
- 月末选股，却吃进了月末当天的涨跌；
- 换手和容量写在纸上很好看，真下单就不是那么回事。

这些全部可测量，而且几乎全都藏在一个 Sharpe 数字里看不见。`strategy-audit` 就是为这件事存在的。

## 它已经抓到过什么

一份不是本项目写的月频策略，交了权重、价格和自报净值。工具先报了两个 BLOCK。

**第一条：** 自报净值比按权重和价格重算的结果高 **4.6%**。后来翻源码才发现，作者把"月频等权"在月内每天 `ffill` 回等权——等于偷偷做了日频再平衡。这部分收益根本不在那张权重表里。

**第二条更麻烦：** 同一份持仓，停牌和缺价按三种合理方式记账，累计收益从 **+99.1%** 一路到 **−3.9%**，差出 **103 个百分点**。这时候谈"因子强不强"没有意义——账都还没记清。

工具里一共 **26 项检查、7 个族**，但有 4 项最值得先看：

| 先看什么 | 它在问什么 |
|---|---|
| **自报净值对账** | 你交的净值，能不能由你交的权重和价格解释 |
| **缺价记账** | 停牌、退市、价格缺失，会把结果推到什么范围 |
| **残差有效注数** | 你以为持有 30 只，实际是不是都在押同一个风险 |
| **盈亏平衡成本** | 单边成本高到多少 bp，这个策略的收益就没了 |

其余检查照常跑。它们不是为了凑一个"26 项体检"，而是帮你判断上面这四件事能不能信。

## 安装

```bash
pip install strategy-audit
```

需要 Python 3.9+。**不内置任何数据源**——它读你的文件、在本地计算。不上传，也不下载。

## 快速开始

把两三个文件扔进去就行。顺序无所谓，工具会自动识别，并把识别结果打印出来——先看它认对没有。

```bash
strategy-audit weights.csv prices.csv nav.csv
```

只有净值也能先查：

```bash
strategy-audit nav.csv
```

还没数据？先看一份内置演示：

```bash
strategy-audit --demo
```

你的**净收益**和**基准**不能靠文件名猜，命令行要明确写出来：

```bash
strategy-audit weights.csv prices.csv \
  --net net_returns.csv \
  --benchmark csi300_returns.csv \
  --trials 20
```

`--trials 20` 的意思是：*"这套策略是从大约 20 个因子/窗口/阈值组合里挑出来的。"* 别把它当装饰。工具没法读懂你的回测历史，只能按你填的次数给 Sharpe 打折。

Python 里一样：

```python
from strategy_audit import audit

report = audit(weights, prices, nav, net=net_returns,
               benchmark=benchmark, n_trials=20)
print(report.text())
```

## 你给什么，就审什么

不需要你把数据整理成某种固定格式。`strategy-audit` 自动识别文件和列名——包括"调仓日 / 证券代码 / 目标权重 / 收盘价 / 成交额"这类中文列名。能审多少，取决于你交了多少：

| 你手上有 | 能审 | 还缺什么 |
|---|---|---|
| 一条净值曲线 | **7 项**——净值质量和策略层显著性 | 权重、价格 |
| 权重 + 价格 | **21 项**——外加前视、换手、记账、风险、处方 | **5 项（缺可选输入）**：成交额、净收益、自报净值 |
| 权重 + 价格 + 成交额 | **24 项**——外加容量、流动性、规模衰减 | 净收益、自报净值 |
| 全部输入 | **26 项**——完整能力矩阵 | — |

"审不了"不等于"通过"。报告会逐项写清楚，每项到底缺什么。

## 自报净值对账（输入契约）

在任何检查敢相信你的数字之前，它先确认这些数字**是你的**。如果你报的净值和你权重、价格重算出来的不是同一条曲线，那下面所有检查审的，都是你从未真正交易过的那个策略。这是整套工具里最该先看的一项。

## 七族检查

这些名词不用记，看报告里的结论就行。列出来，是让你知道每一类问题工具在查什么。

### 前视与记账

调仓日的收益有没有提前吃到？权重是不是带着同期收益的信息？股票池是不是只剩活到样本末的幸存者？缺价按不同政策会差多少？

### 净值质量

这条曲线本身是真的吗？平滑和滞后定价会表现为收益自相关——波动被低估、Sharpe 被高估。净值原地不动，往往说明估值根本没在更新。

### 换手与成本

朴素换手和价格漂移后的实际换手差多少；"用自相关估换手"有没有把成本估偏；成本高到哪里收益归零；如果你同时给了毛收益和净收益，反推你实际扣了多少成本。

### 策略层显著性

收益是不是只靠少数几年或少数几天撑起来？Newey-West 的 lag 一换，结论会不会翻？多重检验折扣之后，Sharpe 还剩多少？

### 风险身份

名义持仓数是不是虚胖？30 只低波、小盘、同行业的票，看着分散，真正独立的风险下注可能没几个。

### 容量与可成交性

涨跌停和停牌时有多少权重下不去；按成交额大概能管多少钱；收益是不是集中在最难成交的票上。它报的是执行风险，不会因为容量小就把回测直接判死。

### 处方（怎么改）

唯一会说"怎么改"的一族——而且带着闸门：它只对**不需要猜未来**的改动给建议，比如砍掉没有价值的权重微调。只有微调占换手 ≥ 20% 才有这个旋钮；名单换血是策略观点，工具不会替你乱删。它拒绝的次数远多于开出处方，"不可处方"不是失败，只说明数据撑不起一个看似聪明的优化。

## 结果怎么读

只有三种等级：

| 标记 | 意思 | 你该做什么 |
|---|---|---|
| **BLOCK** | 这条净值有关键地方解释不通 | 先回到回测代码和数据，修完再谈表现 |
| **WARN** | 结果还能看，但要按报告里的量级打折 | 看影响有多大，别直接拿去开模拟盘或上会 |
| **OK** | 这一项查过了，没发现问题 | 只代表这一项，没给整个策略盖章 |

还有一节叫**"未能检查"**，它很重要。没有成交额列？那容量这一项写的是"没查过"，不是"没问题"。

一个实用的阅读顺序：

1. 先看 **BLOCK**——尤其是自报净值对账和记账政策的结果。
2. 再看盈亏平衡成本和年化单边换手。需要 5bp 成本才赚钱的策略，实际执行大概率很难。
3. 看容量。报告说只能管几千万，你就别拿它解释几个亿的模拟盘。
4. 最后才是 Sharpe、回撤、处方。账没理顺，这些统计做得再精确也没意义。

## 它审不到的三件事

- **因子层面的前视。** 你若用未来数据算因子，再交一张看起来干净的等权表，权重和净值之间可能仍然对得上；等权组合的"权重前视"检查也会显示不适用。
- **你到底试过多少个参数。** `n_trials` 靠你自己填，工具没法读懂你的回测历史。
- **具体是哪一行代码错了。** 它能告诉你"权重表解释不了自报净值"、该往哪个方向查，但不接入策略源码就定位不到那一行。

## 常见误会

**"我只有平台的回测图，能不能用？"**
可以。把日期和累计净值导出来，先跑那 7 项。结果只能说明*这条曲线本身*有没有明显问题。

**"报告全是 OK，是不是可以实盘？"**
不能这么理解。OK 表示查过的项目没发现问题。未提供的数据、策略容量、真实冲击成本和未来表现，都还在工具范围外。

**"报告有 WARN，要不要把策略扔掉？"**
先看 WARN 具体写了什么。容量不足和月末效应是两回事；有的要补数据，有的要打折年化和 Sharpe。

**"为什么一定要我交自报净值？"**
因为这是能抓到最隐蔽 bug 的那一项。权重和价格能重算出*一条*曲线，但平台真正报出来的未必是同一条。

# strategy-audit

审查**回测到净值这一段有没有偷分**。

不告诉你策略好不好 —— 告诉你这份净值能支撑什么结论。

```bash
pip install strategy-audit

strategy-audit --demo                    # 没有数据？先看报告长什么样
strategy-audit 持仓.csv 行情.parquet      # 有数据？直接扔进来
strategy-audit 净值.csv                  # 只有净值曲线？也能审
```

```python
from strategy_audit import audit

rep = audit(weights, prices)     # 顺序无关，列名随便
rep = audit(nav)                 # 只有净值也行
print(rep.text())
```

不用记参数名、不用改列名、不用整理成我们的格式。

## 你有什么 → 能审什么

报告**第一段**就是这张表，明确告诉你边界在哪：

| 你手上有 | 能审 | 审不了 |
|---|---|---|
| 什么都没有 | `--demo` 内置合成数据，零准备 | — |
| 一条净值曲线 | **4 项**（策略层显著性） | 11 项（要权重/价格） |
| 权重 + 价格 | **14 项**（四族几乎全部） | 1 项（毛净对账要净收益） |
| 权重 + 价格 + 净收益 | **15 项**（全部） | — |

**审不了 ≠ 审过通过。** 报告会把审不了的每一项单独列出来，写明缺什么、
补上能多审几项 —— 静默跳过等于让你以为查过了。

### 输入自动识别

列名叫什么都行，中英文都认：

```
date / trade_date / 日期 / 交易日期 / 调仓日
code / ts_code / symbol / 股票代码 / 证券代码
weight / 目标权重 / 持仓 / 仓位
close / 收盘价 / adj_close / 前复权
nav  / 累计净值 / 资金曲线 / 权益
```

形态也不挑：长表、宽表（行=日期、列=股票）、日期在索引上、
`20210104` 这种整数日期，都能认。净值还是收益率按数值特征判别。

识别结果**一定会打印出来让你核对** —— 认错了会让所有检查算在错的东西上，
而报告照样打印得像模像样。

唯一需要你明说的是 `net=` 和 `benchmark=`：一条收益率序列从数值上
无法区分它是策略净收益、基准还是毛收益，三者量级、正负、自相关都一样。
这是少数几个「宁可要求你明说」的地方。

## 四族检查

**族三、族四排在最后跑**，因为它审的是「这个数字可不可信」，
而前两族审的是「这个数字是不是真的」。净值本身偷了分的时候，
再精确的显著性检验也只是把假结论算得更精确。

### 族一：换手与成本真实性（需要权重）

| 检查 | 抓的是 |
|---|---|
| 换手口径 | 朴素 `0.5·Σ\|Δw\|` vs 漂移调整口径 |
| 反推换手偏差 | 自相关反推与实际权重变化的比值 |
| 盈亏平衡成本 | 多大的单边成本吃掉全部超额 |
| 毛净对账 | 你声称扣的成本，实际扣了多少 bp |

### 族二：前视与记账（需要权重 + 价格）

| 检查 | 抓的是 |
|---|---|
| 调仓日对齐 | 用 t 日收盘定权重却吃了 t 日涨幅 |
| 权重前视 | 权重与同期收益相关（vw 用期末市值） |
| 股票池生存者 | 持仓只落在活到末日的标的上 |
| 缺价记账 | 停牌被当退市、三种政策的净值区间 |

### 族三：策略层显著性（只要一条曲线）

| 检查 | 抓的是 |
|---|---|
| 年份集中度 | 超额是否集中在极少数年份 |
| NW lag 敏感性 | 显著性会不会随 lag 选择翻转 |
| 多重检验折扣 | 按你试过的配置数折扣后还剩多少 |
| 回撤与极值 | 最大回撤、恢复期、单期离群点 |

### 族四：风险身份（需要权重 + 价格）

| 检查 | 抓的是 |
|---|---|
| 残差有效注数 | 名义 `1/Σw²` vs 去掉市场后的独立注数 |
| 同规模对照 | 压缩是你**选股**的性质，还是同规模组合都这样 |
| 与 ENB 并列 | 和 Meucci(2009) 有效注数是不是同一个量 |

**这一族刻意不出 BLOCK。** 注数压缩不会让净值算错，它让**风险预算**算错：
按残差独立编的特定风险预算会系统性低估组合残差波动。最高只到 WARN。

市场代理是这族唯一的自造输入：股票池里**不在本账**的标的的等权收益。
这个构造改过两轮，两轮都是合成面板抓出来的，症状都是「注数超过持仓数」——
而注数的硬上界本应是 `1/Σw²`：

| 代理构造 | 问题 | 实测 |
|---|---|---|
| 池子等权均值，所有标的共用 | 每只标的自己在均值里 ⇒ β 被推向 1，残差压出 −1/(K−1) 负相关 | 60 只池持 20 只报 **28.9 注**（解析预测 29.5） |
| 留一（代理不含自己） | 修好了无因子情形；但真有共同因子时 β≈1，代理仍含**其他持仓**的特有项 | 单因子面板仍报 **28.9 注** |
| **持仓之外**（当前） | 代理与任何持仓都不共享特有项 ⇒ 负相关通道消失 | 独立面板 **19.98 注**（应 20） |

当前构造的残余偏差是**正**的一小项：所有持仓共享代理自身的特有噪声
（`Var ≈ σ²/C`，C = 非持仓标的数）⇒ 注数被**低估**、问题被**高报**，
对审计工具是安全方向。这一项可解析预测（`b ≈ ne/(1+(ne−1)/C)`，实测与
预测吻合到 2%），所以报告会把去偏后的值一并给出，避免小股票池假装成告警。
C 不足 10 只时退回留一，并在报告里写明退回了。

## 真实面板端到端验证

在真实 A 股面板上跑（800 只 / 2015-2026 / 2787 交易日 / 126 期月频），
策略是 20 日反转、市值加权、选 30 只 —— 同一个投资逻辑造两版，
只有实现细节不同：

| | careless | careful |
|---|---|---|
| 信号时点 | 调仓日收盘（收市后才拿到） | 滞后一日 |
| 权重口径 | 调仓日市值（含当日收益） | 上一调仓日市值 |
| 股票池 | 样本末仍在册的名单 | 调仓日当时可见 |
| **毛年化** | **6.19%**（Sharpe 0.34） | **3.63%**（Sharpe 0.26） |
| 审计结论 | 1 项 BLOCK | 0 项 BLOCK |

三处漏口合起来把毛年化抬高 **2.56pp（+71%）**。逐个隔离：信号同日
+2.11pp、权重同日 cap +0.76pp、股票池生存者 +0.01pp。

复现：`python examples/real_ashare_e2e.py`（需自备面板，路径在脚本顶部）。

## 工具自己被抓到的七个错

这些是开发过程中**测试和真实数据抓到我自己写错的地方**，
每个都钉了回归测试。列出来是因为它们决定了这个工具为什么这样设计。

### 真实数据抓到的（合成面板测不出来）

**① 停牌被误判成退市。** 真实面板上 24 个「持有但无价格」事件
**100% 都是停牌**（之后全部复牌），工具却全报成「记账政策决定结论」+BLOCK。
合成面板里"消失"就是永久消失，所以测不出这个区别。现在会先分类，
全是停牌时说清楚「全额清算在停牌上是错的记账 —— 停牌股会复牌，不该记 −100%」。

**② 小而一致的前视被幅度门槛放过。** 把权重改成按**下期**市值加权
（教科书 vw 前视），毛年化从 3.63% 跳到 **13.85%**（近 4 倍），
而截面秩相关只有 **+0.088**（t=4.15）。原门槛要求 `|corr| ≥ 0.10`，
于是这个铁证判了 OK。30 只持仓上真前视就是「小而一致」——
**一致性才是证据，幅度只是效应量**。

### 误报率抓到的（固定门槛都是错的）

**③ 集中度固定门槛误报 61%。** 「最好两年占正收益 > 50%」看着合理，
但 400 次纯噪声模拟里零分布的**中位数就是 0.53** —— 门槛定在中位数以下，
等于一半的干净策略都被报警。现在按**置换零分布的分位**判：
把同一批收益随机打散到各年，看这个占比本来能有多高。误报率降到 10%，
检出率仍是 100%。

**④ 单期占比门槛误报 27%。** 「最好一期占累计收益 > 30%」的问题是
累计收益接近 0 时分母趋零，纯噪声下 p90 就有 0.78、p95 达 1.45。
改判「这一期在收益分布里是不是离群点（>4σ）」—— 与累计收益大小无关，
而这才是「数据可能有错」的真信号。

**⑤ NW lag 跨线误报 16%。** 16% 的干净序列会在 lag 扫描中跨过 |t|=2，
跨度中位数仅 0.57 —— 那是噪声。而 t 从 3.30 到 6.93（比值 2.10）
反而被 BLOCK 了，尽管**两端都远超显著线、结论根本没变**。
现在只在「结论真的翻转且跨度 ≥ 1.0」时报警：误报 3%，
两端同侧时 0% 误报。

### 识别检验抓到的

**⑦ 同规模对照漏传权重，把加权差异当成了选股效果。** 族四的对照要回答
「这个注数压缩是你**选股**的性质，还是任何同规模组合都这样」——
所以除了「挑哪些名字」，股票池、窗口、加权、估计器都必须固定。
代码漏传了权重向量：本账是市值加权、对照却是等权，于是真实面板上报出
「本账 7.0 注 vs 对照 30.7 注」并判 WARN。

报告自己就带着反证：同一批持仓改成等权是 **11.3 注**（不是 7.0），
所以 7.0→30.7 的绝大部分差异来自加权方式，不是选股。修好后对照
**12.2 注**、结论从 WARN 变 **OK**。

**教训**：对照组每多变一个东西，结论就多一个混淆源。写"固定 X/Y/Z"的
注释不等于代码真的固定了 —— 那句注释当时就在函数文档里。

### 单位对账抓到的

**⑥ Sharpe 的 t 被夸大 3.4 倍。** 同一条序列，`Sharpe/SE` 算出 t=3.43，
而 `NW lag=0` 只有 1.02。两者测的是同一件事，对不上就说明有一个错了 ——
是我把**周期**口径的方差项和**年化**口径的 Sharpe 混在一个式子里。
修好后两个独立估计在 4 组种子上差异 ≤ 1.3%（实测最大 1.20%）。

**这条是方法**：凡是能用两条独立路径算的量，就都算一遍对账。
`period_returns()` 与 `daily_path()` 也是这样（偏差 4.5e-16）——
闸门自己也会标定错，只有对账能抓到。

## 敌意输入不会崩，也不会给你空报告

12 种敌意输入逐个测过（`tests/test_robustness.py`）：单行表、全 NaN、
日期全重复、倒序日期、含 ±inf、净值全 0、常数净值、只有日期列、负净值、
1e300、空表。规则是**要么给结论，要么给明确原因**，不许两者都没有。

这一轮抓到两个问题：净值里一个 `inf` 会让 NW t 的方差计算崩在
`invalid value in scalar divide`（用户根本不知道是哪行数据）；而单行表 /
全 NaN / 净值全 0 会返回 0 条结论、0 个 BLOCK —— 一份**空报告比报错更让人
无从下手**。现在无效值会被丢弃并明确告知，跑不起来时会说清最低需要什么。

报告里也不许漏出 `nan`：收益恒定时「距均值 nan 个标准差」这种话会让人
以为工具坏了，该说的是「收益无波动，离群判定不适用」。

## 输入契约会 BLOCK 的三件事

只有这三种情况会拦住你，因为它们会让下游**静默算错**：

**权重有空值** —— 不会替你 `fillna(0)`。空值有两种含义：「这期不持有」(=0) 与
「数据没取到」(未知)。当成 0 会把数据缺失记成主动清仓，而清仓在换手里是一笔
真实交易 —— 凭空造出成本。

**面板有重复行** —— `pivot` 会静默保留其中一行，而两行的值可能不同。
（实测真实面板出现过：某月两日共 11998 重复行。）

**权重和不为 1**（偏离 > 1%）—— 权重和 0.95 有两种可能：有意留了 5% 现金
（归一会抹掉现金拖累这个真实收益来源），或者权重算错了（不归一则净值口径错）。
工具不替你判断是哪一种。

其余情况一律「能审的先审，审不了的说清楚」。

## 与 factor-audit 的分工

| | 审什么 |
|---|---|
| [factor-audit](https://github.com/val1813/factor-audit) | **信号层**：检验做没做对（IC、NW t、独立簇 Bonferroni、衰减、集中度、六项面板体检） |
| strategy-audit | **组合层**：信号到净值这一段（换手成本、前视、成分记账、策略层显著性） |

共用 `date/code/close` 价格面板契约，可以串起来用：

```python
from factor_audit import check_panel
from strategy_audit import audit

print(check_panel(prices).text())   # 先体检数据
print(audit(weights, prices).text())     # 再审组合
```

`strategy-audit` 的股票池生存者检查依赖价格面板本身含退市股。若面板是纯生存者
面板，它会说**「无法判定」**而不是 OK。

## 报告怎么读

三级：**BLOCK**（净值不可信，先修）、**WARN**（可用但按给出的量级打折）、
**OK**（查过了，通过）。外加**未能检查**一节。

跳过的理由必须**说对**。等权组合的权重没有截面变化，权重-收益相关系数在数学上
无定义 —— 那不是「持仓过少」。报错原因会让人去修一个不存在的问题，然后对
后续所有告警都不再相信。

每个负结果都附**最小可检出效应**：「没查出问题」和「查不出这么小的问题」
是两回事。

CLI 退出码：有 BLOCK 返回 1，方便进 CI。**WARN 不算失败** ——
让 WARN 挂 CI 会逼你去关告警。

## 三件它不做的事

- **不告诉你策略好不好** —— 判「能不能上」需要你的收益预期和执行现实
- **不替你选成本假设** —— 主输出是盈亏平衡成本，那不需要任何假设：
  「你的策略需要单边成本低于 X bp 才有正超额」。X 很小就是坏消息，
  不管你的真实费率是多少
- **不上传任何东西** —— 全本地运行，持仓不出你的进程

## 数据由你提供

不内置数据源，也不分发行情（版权）。实测免费源会拉黑 IP、非线程安全、
对退市股返回「空 + success」—— 把它们做成依赖，等于把它们的失败变成
本工具的失败，而你会认为是我们坏了。

**策略不用「接」**：策略就是你的权重表，我们不需要理解你的逻辑。
